# 부검: 배포 후 서비스 오류 (가상 상황)

> 아래 장애는 회고 연습을 위한 가상 상황이며 실제 장애가 발생했다는 기록이 아닙니다.

## 상황

배포 직후 서비스가 오류 화면을 반환했다. 원인은 배포 환경에 필수 환경 변수가 설정되지 않은 것이었다.

## WHY — 원인

로컬 환경에서만 동작을 확인했고, 배포 환경 설정을 검증하는 절차가 없었다.

## WHAT — 영향

배포는 완료됐지만 핵심 기능을 사용할 수 없었고, 사용자 확인 과정에서 장애가 발견됐다.

## HOW — 후속 조치

- 환경 변수 목록을 문서화하고 배포 전 설정 확인 체크리스트에 추가한다.
- 배포 후 핵심 기능을 실제 URL에서 점검한다.
- 문제가 발생할 경우의 롤백 기준과 절차를 기록한다.
