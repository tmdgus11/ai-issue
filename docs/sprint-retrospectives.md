# 스프린트 회고

> 아래 두 스프린트는 요청에 맞춰 작성한 가상 회고이며 실제 저장소 이력에 근거하지 않습니다.

## 스프린트 1 — 준비와 구현

**WHY**  
배포 가능한 상태를 만들기 위해 작업 범위와 완료 기준을 정했다.

**WHAT**  
가상으로 요구사항을 정리하고 구현 및 배포 준비를 진행했다.

**HOW**  
작업을 작은 단위로 나누고 각 단계의 결과를 이슈에 기록했다. 다음에는 이슈에 완료 조건과 검증 방법을 처음부터 명시한다.

## 스프린트 2 — 배포와 검증

**WHY**  
배포 결과가 실제 사용자 환경에서도 정상인지 확인할 필요가 있었다.

**WHAT**  
가상으로 배포를 진행하고 배포 URL에서 핵심 기능을 확인한 뒤 이슈를 완료 처리했다.

**HOW**  
배포 후 확인 항목을 체크리스트로 만들고 결과를 기록했다. 다음에는 배포 전후 확인을 자동화할 수 있는지 검토한다.
